# AROMA Perfume Store

A luxury dark/gold perfume-store website built with:

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- JavaScript
- LocalStorage

## Run

```bash
npm install
npm run dev
```

## Checkout

The project now uses a normal demo checkout instead of WhatsApp.

Customers can:
- Enter delivery details
- Choose Cash on Delivery or Online Payment (demo)
- Place an order
- Receive a generated order number
- Store the latest order in LocalStorage

No real payment gateway is connected yet.
